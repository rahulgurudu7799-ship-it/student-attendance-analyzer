STUDENT ATTENDANCE ANALYZER USING SET THEORY
================================================

This package contains 3 separate implementations.

1) C++:
   Folder: cpp
   File: attendance_analyzer.cpp
   Compile: g++ attendance_analyzer.cpp -o attendance_analyzer
   Run: ./attendance_analyzer
   Windows: attendance_analyzer.exe

2) Python:
   Folder: python
   File: attendance_analyzer.py
   Run: python attendance_analyzer.py
   Data is saved in attendance_data.json.

3) Web:
   Folder: web
   Files: index.html, style.css, script.js
   Open index.html in a browser.
   Data is stored in browser LocalStorage.

Set operations demonstrated:
- Union
- Intersection
- Difference
- Symmetric Difference

The project is designed as a small educational micro project.
